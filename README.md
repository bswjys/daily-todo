# 데일리 투두

달력에서 날짜를 고르고, 매일 챙기는 12가지 루틴을 체크하는 개인용 투두리스트 PWA입니다.
그날그날 생각나는 일은 목록 맨 아래 빈칸에 바로 적어 그날만 체크할 수 있습니다.
토스 앱처럼 화이트·연회색 카드에 토스 블루(`#3182F6`) 한 가지 색만 쓰는 심플한 화면입니다.

- 라이브: https://bswjys.github.io/daily-todo/
- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 전체 화면으로 뜹니다.

## 화면

1. **월간 달력** — `‹ 2026년 11월 ›` 이동, `오늘` 버튼. 날짜를 누르면 바로 아래 목록이 그날로 바뀝니다.
   날짜 칸은 그날의 달성률에 따라 색이 진해집니다.
   - 0%: 흰 칸
   - 1~49%: 연한 파랑
   - 50~99%: 중간 파랑
   - 100%: 진한 파랑 + ✓
2. **요약 바** — `오늘 4 / 14 완료`, 진행 막대, 남은 개수. 다 채우면 `오늘 할 일을 모두 끝냈어요! 🎉`
3. **할 일 목록** — **동그라미 체크 + 항목 이름**만 있는 12줄. 체크는 날짜마다 따로 `localStorage`에 자동 저장됩니다.
4. **맨 아래 빈칸** — `+ 생각나는 일을 적어보세요` 칸에 그날 생각난 일을 적고 **Enter** 또는 `추가`를 누르면
   그 날짜에만 항목이 생깁니다. 기본 12개와 똑같이 동그라미로 체크하고, 오른쪽 `✕`로 지웁니다(6초 `되돌리기`).
   요약 개수와 달력 색에도 함께 잡힙니다(예: 기본 12 + 그날 2 = `14`개 기준).
5. **항목 편집** (오른쪽 위) — 이름 수정, 위/아래 순서 이동, 삭제(되돌리기 토스트), 새 항목 추가.
   편집한 목록은 모든 날짜에 함께 반영됩니다.
6. **기록 백업** (편집 시트 아래) — `JSON 내보내기` / `불러오기`.

## 데이터

`localStorage` 키 `daily-todo-v1` 하나에 전부 들어갑니다.

```json
{
  "v": 2,
  "items": [{ "id": "d1", "name": "장신대 성경문제" }],
  "days": {
    "2026-11-25": {
      "done": { "d1": true, "emwvyri0qh4ja": true },
      "extra": [{ "id": "emwvyri0qh4ja", "name": "약국 들르기" }],
      "memo": {}
    }
  }
}
```

- `items`는 모든 날짜에 공통인 기본 항목, `days[날짜].extra`는 **그날만** 추가한 항목입니다.
- `memo`는 예전 버전의 항목별 메모 자리입니다. 화면에서는 더 쓰지 않지만 **지우지 않고 그대로 보존**하므로,
  예전 기록이 있는 기기에서도 데이터가 깨지지 않습니다(불러오기·내보내기에도 함께 실립니다).
- 날짜 키는 기기 시간대 기준 `YYYY-MM-DD`입니다.
- 기록은 기기 안에만 저장되고 서버로 보내지 않습니다.
- **아이폰에서는 홈 화면에 추가한 앱과 사파리 탭의 저장 공간이 서로 다릅니다.** 한쪽에서 쓰던 기록을 옮기려면 편집 시트의 `JSON 내보내기` → 다른 쪽에서 `불러오기`를 쓰면 됩니다.

## 검증

```bash
LD_LIBRARY_PATH=/workspace/.browserlibs/lib python3 test_app.py
```

- 기본 12개 항목·순서, 항목별 메모 입력칸이 없고 '체크 + 이름'만인지
- 맨 아래 빈칸: Enter·`추가` 버튼으로 그날 항목 추가, 체크, `✕` 지우기·되돌리기, 새로고침 유지, 날짜별 독립
- 요약 카운트·달력 색이 그날 추가 항목까지 포함(1~49 / 50~99 / 100% + ✓)
- 예전 데이터(항목별 메모 포함) 호환, 깨진 저장값 복구
- 항목 추가·이름 수정·순서 이동·삭제·되돌리기, JSON 내보내기·불러오기
- 콘솔 오류 0, 가로 넘침 0 (390 / 1280)
- 스크린샷: `shots/` (대표 이미지는 `downloads/daily_todo/`)

## 배포

`main` 브랜치 루트가 그대로 GitHub Pages에 올라갑니다. (`.nojekyll` 포함)
Pages를 켠 뒤에는 `index.html`, `styles.css`, `app.js`를 고쳐 푸시하면 다음 접속부터 바로 반영됩니다.
서비스워커 캐시는 `sw.js`의 `CACHE`/`VERSION`을 함께 올려 주세요(현재 `daily-todo-v2` / `2`, `index.html`은 `?v=2`).
